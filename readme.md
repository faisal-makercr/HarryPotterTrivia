# Harry Potter Trivia 
This is a Harry Potter Trivia website where users can come and give trivia of the character they wants to.

## Why You should visit this website?
On visiting the website you will first be dropped to the home page where you can select from the different characters and once you select a character you will be taken to that character's page where you can select to give the character based trivia and also check the high score of that character.
After giving a trivia you will be asked to give your name and save it to see it later on hihg score page if it was a high score and there are many more features to look for.
